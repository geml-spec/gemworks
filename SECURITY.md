# Security Policy

Gemworks follows the GEML project's security policy. Supported versions,
scope notes, and response expectations all live there:

**[GEML's SECURITY.md](https://github.com/geml-spec/geml/blob/main/SECURITY.md)**

## Reporting a vulnerability

Report privately via **GitHub Security Advisories**: on the
[repository page](https://github.com/geml-spec/gemworks), *Security → Report a
vulnerability*. This reaches the maintainer directly and keeps the report
confidential until a fix is released.

Please do not open a public issue for a security report.
